### Shipped

**[MeetOut](https://meetouthq.com)** — AI content repurposing
Turn anything you've read, watched, or noted into a week of publish-ready social posts. One source — a URL, PDF, pasted text, or audio — runs through a switchable LLM pipeline to produce platform-native posts for 8 channels (LinkedIn, X, Bluesky, Instagram, Facebook, Threads, newsletter, YouTube), each in the target platform's own format. A second mode turns uploaded video into trimmed, ready-to-post clips through an FFmpeg render pipeline with a background job worker. Built entirely end to end.
<sub>React · Vite · FastAPI · SQLAlchemy · Postgres/Supabase · OpenAI (GPT-4o + Whisper) · Anthropic · Razorpay · Vercel · Railway</sub>

**[BrandKit](https://thebrandkit.com)** — generative brand identity
Generate a complete brand kit — palette, font pairings, and logos — in one pass, built on real algorithms rather than a single API call: HSL/color-theory palettes, curated Google Font pairings, and SVG-composed logos, with one LLM call for copy and a templated fallback so the product never breaks when the model is unavailable.
<sub>React · TypeScript · FastAPI · SQLAlchemy · Alembic · Postgres/Supabase · Razorpay</sub>

**Under the hood, both** — the unglamorous parts, done right:
JWT + Google OAuth · Razorpay subscriptions with idempotent webhooks · Postgres row-level security · OAuth tokens encrypted at rest (Fernet) · signed-state CSRF protection · server-enforced plan limits.
